Sobre

Este projeto foi desenvolvido com o objetivo de praticar a criação de interfaces web responsivas utilizando HTML, CSS e JavaScript.

A proposta simula uma landing page voltada para serviços de Quality Assurance (QA), apresentando conceitos relacionados a testes manuais, análise de bugs, validação de interfaces e experiência do usuário.

Serviços

🧪 Casos de Teste

Criação e documentação de cenários de testes manuais.

🐞 Bug Reports

Registro detalhado de falhas e inconsistências encontradas.

🎨 Validação de Interfaces

Verificação da experiência visual e funcional das páginas.
