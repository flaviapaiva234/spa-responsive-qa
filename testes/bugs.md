## BUG-001 — Botão “Ver Serviços” ocupa largura excessiva no mobile

### Severidade
Baixa

### Prioridade
Baixa

### Ambiente
- Navegador: Google Chrome
- Resolução: Mobile (400px)

### Passos para reproduzir
1. Abrir a aplicação
2. Ativar modo responsivo no DevTools
3. Selecionar resolução mobile
4. Observar botão “Ver Serviços”

### Resultado atual
O botão ocupa largura muito grande em telas pequenas.

### Resultado esperado
O botão deveria possuir largura mais equilibrada no layout mobile.
