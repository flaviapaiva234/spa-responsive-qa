🧪 Casos de Teste

Documentação dos principais testes manuais executados no projeto SPA Responsive QA.

CT-001 — Verificar carregamento da página inicial

Objetivo: validar se a página principal carrega corretamente.

Pré-condição: servidor Live Server em execução.

Resultado esperado: exibir menu, título principal, botão, cards, depoimentos e footer.

Status: ✅ Aprovado

CT-002 — Verificar funcionamento do menu de navegação

Objetivo: validar se os links do menu direcionam corretamente para as seções da página.

Resultado esperado: navegação suave até a seção correspondente.

Status: ✅ Aprovado

CT-003 — Verificar responsividade em resolução mobile

Objetivo: validar adaptação do layout em dispositivos móveis.

Resultado esperado: cards reorganizados, textos legíveis e menu funcional.

Status: ✅ Aprovado
