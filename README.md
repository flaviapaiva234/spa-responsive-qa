# 💻 SPA Responsive QA

## 📖 Sobre o Projeto

Este projeto consiste no desenvolvimento de uma SPA (Single Page Application) responsiva voltada para apresentação de serviços e portfólio na área de QA (Quality Assurance).

A aplicação foi desenvolvida com foco em:

- Organização visual
- Responsividade mobile
- Experiência do usuário
- Estruturação de páginas HTML
- Estilização moderna com CSS
- Interatividade utilizando JavaScript

O objetivo do projeto é simular uma landing page profissional para serviços de QA, contendo funcionalidades interativas e documentações voltadas para testes manuais.

## 🧠 Assistente Interativo de QA

O projeto possui um Assistente Interativo de QA inspirado em experiências interativas modernas.

O usuário responde perguntas rápidas relacionadas à validação da aplicação e recebe automaticamente um resumo final da análise QA.

Exemplos de validação:

- Funcionamento do carregamento da aplicação
- Navegação entre seções
- Organização visual dos cards
- Responsividade mobile
- Legibilidade dos textos

O sistema utiliza JavaScript para:

- Manipular perguntas dinamicamente
- Controlar progresso das perguntas
- Processar respostas
- Exibir análise automática ao final
